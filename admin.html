Comment configurer Firebase

  1. Va sur console.firebase.google.com et crée un projet
  2. Active Firestore Database (mode production ou test)
  3. Dans Paramètres → Tes applications → ajoute une app Web
  4. Copie les clés ci-dessous et clique Sauvegarder
  5. Dans les règles Firestore, autorise les lectures publiques pour le site
